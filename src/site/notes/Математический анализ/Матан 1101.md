## Введение в логику и доказательства

Лектор подчеркивает важность строгой логической записи математических утверждений.

- Универсальные утверждения:  
    $$\forall x \in X, \; P(x) \quad \text{(«Для любого } x \text{ из множества } X \text{ выполняется предикат } P(x)\text{»)}$$
- Утверждения о существовании:  
    $$\exists x \in X : P(x) \quad \text{(«Существует } x \text{ из множества } X \text{ такой, что выполняется } P(x)\text{»)}$$
- Пример записи теоремы Пифагора:  
    $$\forall \triangle \in \text{Треугольники}, \; (\text{прямоугольный}(\triangle) \implies a^2 + b^2 = c^2)$$

## Отрицание и доказательство от противного

Для доказательства теоремы $T$ часто используется метод от противного: доказывается, что отрицание $\neg T$ ложно.

- Отрицание импликации: Отрицанием общего утверждения вида $\forall x, (A(x) \implies B(x))$ является утверждение существования:  
    $$\exists x : (A(x) \land \neg B(x))$$
    
    - _Пример:_ Утверждение «Любой студент, если посетит все лекции, то получит 5» ложно, если найдется хотя бы один студент, который посетит все лекции и не получит 5.
    
- Контрпример: Для опровержения утверждения $\forall x \in \mathbb{N}, (x \vdots 3 \implies x \vdots 6)$ достаточно привести контрпример $x$ = 3: число $3 \vdots 3$, но $3 \not\vdots 6$.

## Ограниченность множеств

Рассматривается числовое множество $X \subseteq \mathbb{R}$.

- Ограниченность сверху: Множество $X$ ограничено сверху, если:  
$$\exists a \in \mathbb{R} : \forall x \in X, \; x \le a \quad (a \text{ — верхняя грань})$$
- Ограниченность снизу: Множество $X$ ограничено снизу, если:  
$$\exists b \in \mathbb{R} : \forall x \in X, \; x \ge b \quad (b \text{ — нижняя грань})$$
- Критерий ограниченности: Множество $X$ ограничено (и сверху, и снизу) тогда и только тогда, когда:  
$$\exists C \ge 0 : \forall x \in X, \; \vert{}x\vert{} \le C$$

## Точные грани (Супремум и Инфимум)

- Точная верхняя грань (супремум): $M = \sup(X)$ — это наименьшая из всех верхних граней.  
    Условия определения:
    
    1. $∀ x ∈ X, x ≤ M$
    2. $∀ M' < M, ∃ x ∈ X : x > M'$
    
- Точная нижняя грань (инфимум): $m = \inf(X)$ — это наибольшая из всех нижних граней.  
    Условия определения:
    
    1. $∀ x ∈ X, x ≥ m$
    2. $∀ m' > m, ∃ x ∈ X : x < m'$

## Свойства точных граней

Для любых непустых множеств $X, Y \subseteq \mathbb{R}$ справедливы следующие свойства:

### Сумма множеств

- $\sup(X + Y) = \sup(X) + \sup(Y)$
- $\inf(X + Y) = \inf(X) + \inf(Y)$

### Противоположное множество

- $\sup(-X) = -\inf(X)$
- $\inf(-X) = -\sup(X)$

### Вложение множеств

Если $X$ ⊆ $Y$, то:

- $\inf(Y) \le \inf(X)$
- $\sup(X) \le \sup(Y)$

_Примечание: Для пустого множества ∅ любое число $c \in \mathbb{R}$ одновременно является и верхней, и нижней гранью, поэтому $\sup(\emptyset)$ и $\inf(\emptyset)$ не существуют._
