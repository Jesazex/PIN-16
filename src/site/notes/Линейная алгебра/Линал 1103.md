## Произведение векторов

### 1. Скалярное произведение

- Ортогональность векторов: Необходимым и достаточным условием ортогональности (перпендикулярности) двух векторов является равенство их скалярного произведения нулю:  
    $$\vec{a} \perp \vec{b} \iff (\vec{a}, \vec{b}) = 0$$
- Проекция вектора: Скалярное произведение используется для нахождения проекции одного вектора на направление другого.

### 2. Векторное произведение

- Коллинеарность векторов: Необходимым и достаточным условием коллинеарности двух векторов является равенство их векторного произведения нулевому вектору:  
    $$\vec{a} \times \vec{b} = \vec{0}$$
- Вычисление площади: Модуль векторного произведения двух векторов равен площади параллелограмма, построенного на этих векторах. Площадь треугольника составляет половину этой величины:  
    $$S_{\text{пар}} = \vert{}\vec{a} \times \vec{b}\vert{}, \quad S_{\text{тр}} = \frac{1}{2}\vert{}\vec{a} \times \vec{b}\vert{}$$

### 3. Смешанное произведение

Смешанное произведение трех векторов $\vec{a}$, $\vec{b}$, $\vec{c}$ вычисляется через определитель третьего порядка, составленный из их координат.

- Ориентация векторов:
    
    - Если $(\vec{a}, \vec{b}, \vec{c}) > 0$, то тройка векторов — правая.
    - Если $(\vec{a}, \vec{b}, \vec{c}) < 0$, то тройка векторов — левая.
    
- Вычисление объема:
    
    - Объем параллелепипеда: Равен модулю смешанного произведения векторов, на которых он построен:  
        $$V_{\text{пар}} = \vert{}(\vec{a}, \vec{b}, \vec{c})\vert{}$$
    - Объем пирамиды (тетраэдра): Равен $\frac{1}{6}$ модуля смешанного произведения:  
        $$V_{\text{пир}} = \frac{1}{6}\vert{}(\vec{a}, \vec{b}, \vec{c})\vert{}$$

## Прямая на плоскости

### 1. Уравнение линии

Уравнение вида $F(x, y) = 0$ называется уравнением линии $L$, если ему удовлетворяют координаты любой точки, лежащей на этой линии, и не удовлетворяют координаты точек, не лежащих на ней.

- Алгебраическая линия: Линия, уравнение которой можно представить в виде $P(x, y) = 0$, где $P(x, y)$ — многочлен. Порядок линии $n$ определяется наивысшей суммарной степенью переменных в его членах.
- Трансцендентная линия: Всякая неалгебраическая линия.

### 2. Общее уравнение прямой

Всякое уравнение вида  
$$Ax + By + C = 0$$  
где $A, B, C \in \mathbb{R}$, причем $A^2 + B^2 \neq 0$, определяет на плоскости прямую линию.

- Нормальный вектор: Вектор $\vec{n} = (A, B)$ перпендикулярен этой прямой.
- Неполные уравнения прямой:
    
    1. $C = 0 \implies Ax + By = 0$ — прямая проходит через начало координат.
    2. $A = 0 \implies By + C = 0$ — прямая параллельна оси $Ox$ (горизонтальная).
    3. $B = 0 \implies Ax + C = 0$ — прямая параллельна оси $Oy$ (вертикальная).
    4. $A = 0, \, C = 0 \implies y = 0$ — уравнение оси $Ox$.
    5. $B = 0, \, C = 0 \implies x = 0$ — уравнение оси $Oy$.
    
- Тождественность прямых: Два общих уравнения $A_1x + B_1y + C_1 = 0$ и $A_2x + B_2y + C_2 = 0$ определяют одну и ту же прямую тогда и только тогда, когда их коэффициенты пропорциональны:  
    $$\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2}$$

### 3. Уравнения прямой через направляющий вектор

- Направляющий вектор: Любой ненулевой вектор $\vec{q} = (l, m)$, параллельный прямой $L$.
- Параметрические уравнения: Если прямая проходит через точку $M_0(x_0, y_0)$ параллельно вектору $\vec{q} = (l, m)$:  
    $$\begin{cases} x = x_0 + lt \\ y = y_0 + mt \end{cases}$$  
    где $t$ — параметр.
- Каноническое уравнение: Получается из параметрических уравнений исключением параметра $t$:  
    $$\frac{x - x_0}{l} = \frac{y - y_0}{m}$$
- Уравнение прямой, проходящей через две точки $M_1(x_1, y_1)$ и $M_2(x_2, y_2)$:  
    $$\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1}$$

### 4. Уравнение прямой с угловым коэффициентом

- Угол наклона ($\alpha$): Угол, образованный прямой с положительным направлением оси $Ox$.
- Угловой коэффициент ($k$): Тангенс угла наклона, $k = \tan\alpha$.
- Уравнение линии:  
    $$y = kx + b$$  
    где $b$ — ордината точки пересечения прямой с осью $Oy$.
- Уравнение по точке и угловому коэффициенту: Для прямой, проходящей через точку $M_0(x_0, y_0)$ с коэффициентом $k$:  
    $$y - y_0 = k(x - x_0)$$

## Угол между двумя прямыми

### 1. Прямые заданы общими уравнениями

Для прямых $A_1x + B_1y + C_1 = 0$ и $A_2x + B_2y + C_2 = 0$:  
$$\cos\phi = \frac{\vert{}A_1A_2 + B_1B_2\vert{}}{\sqrt{A_1^2 + B_1^2} \cdot \sqrt{A_2^2 + B_2^2}}$$

- Условие параллельности: $\frac{A_1}{A_2} = \frac{B_1}{B_2}$
- Условие перпендикулярности: $A_1A_2 + B_1B_2 = 0$

### 2. Прямые заданы каноническими уравнениями

С направляющими векторами $\vec{q}_1 = (l_1, m_1)$ и $\vec{q}_2 = (l_2, m_2)$:

- Условие параллельности: $\frac{l_1}{l_2} = \frac{m_1}{m_2}$
- Условие перпендикулярности: $l_1l_2 + m_1m_2 = 0$

### 3. Прямые заданы уравнениями с угловыми коэффициентами

Для прямых с коэффициентами $k_1$ и $k_2$:  
$$\tan\phi = \left\vert{}\frac{k_2 - k_1}{1 + k_1k_2}\right\vert{}$$

- Условие параллельности: $k_1 = k_2$
- Условие перпендикулярности: $k_1k_2 = -1 \implies k_2 = -\frac{1}{k_1}$

## Нормированное (нормальное) уравнение прямой

Уравнение вида:  
$$x \cos\alpha + y \sin\alpha - p = 0$$  
где $p$ — расстояние от начала координат до прямой, а $\alpha$ — угол перпендикуляра к прямой с положительным направлением оси $Ox$.

- Переход от общего уравнения $Ax + By + C = 0$ к нормированному осуществляется умножением на нормирующий множитель $\mu$:  
    $$\mu = \pm \frac{1}{\sqrt{A^2 + B^2}}$$  
    _Знак $\mu$ выбирается противоположным знаку свободного члена $C$._

## Расстояние от точки до прямой

Расстояние $d$ от точки $M_0(x_0, y_0)$ до прямой, заданной общим уравнением $Ax + By + C = 0$, вычисляется по формуле:  
$$d = \frac{\vert{}Ax_0 + By_0 + C\vert{}}{\sqrt{A^2 + B^2}}$$  
_Данное значение равно модулю выражения, полученного подстановкой координат точки в левую часть нормированного уравнения прямой._
