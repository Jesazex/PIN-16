## Основные понятия векторной алгебры

В рамках данного раздела изучаются геометрические векторы (направленные отрезки). Точка приложения вектора в линейной алгебре не имеет значения (векторы считаются свободными и могут переноситься параллельно в любую точку пространства).

- Обозначение: $\vec{a}$ или $\overrightarrow{AB}$, где $A$ — начало вектора, $B$ — его конец.
- Длина (модуль) вектора: Длина отрезка, изображающего вектор. Обозначение: $\vert{}\vec{a}\vert{}$ или $\vert{}\overrightarrow{AB}\vert{}$.
- Нулевой вектор: Вектор, у которого начало и конец совпадают. Имеет нулевую длину и неопределенное направление. Обозначение: $\vec{0}$.
- Коллинеарность: Векторы называются коллинеарными, если они лежат на одной прямой или на параллельных прямых ($\vec{a} \parallel \vec{b}$).
    
    - Сонаправленные векторы: $\vec{a} \uparrow\uparrow \vec{b}$.
    - Противоположно направленные векторы: $\vec{a} \uparrow\downarrow \vec{b}$.
    
- Равенство векторов: Два вектора $\vec{a}$ и $\vec{b}$ называются равными ($\vec{a} = \vec{b}$), если они:
    
    1. Коллинеарны ($\vec{a} \parallel \vec{b}$).
    2. Сонаправлены ($\vec{a} \uparrow\uparrow \vec{b}$).
    3. Имеют равные длины ($\vert{}\vec{a}\vert{} = \vert{}\vec{b}\vert{}$).
    
- Противоположный вектор: Вектор, имеющий ту же длину, но противоположное направление по отношению к $\vec{a}$. Обозначение: $-\vec{a}$.

## Линейные операции над векторами

### Сложение векторов

Суммой векторов $\vec{a}$ и $\vec{b}$ называется третий вектор $\vec{c} = \vec{a} + \vec{b}$.

- Правило треугольника: Если вектор $\vec{b}$ приложен к концу вектора $\vec{a}$, то вектор суммы соединяет начало $\vec{a}$ с концом $\vec{b}$.
- Правило параллелограмма: Если векторы $\vec{a}$ и $\vec{b}$ отложены из одной точки, то вектор суммы совпадает с диагональю параллелограмма, исходящей из этой же точки.
- Свойства сложения:
    
    - Коммутативность: $\vec{a} + \vec{b} = \vec{b} + \vec{a}$.
    - Ассоциативность: $(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$.
    - Свойство нулевого вектора: $\vec{a} + \vec{0} = \vec{a}$.
    - Свойство противоположного вектора: $\vec{a} + (-\vec{a}) = \vec{0}$.
    
- Правило многоугольника: При сложении нескольких векторов они выстраиваются «цепочкой» один за другим. Вектор суммы соединяет начало первого вектора с концом последнего.

### Разность векторов

Разностью векторов $\vec{a}$ и $\vec{b}$ называется такой вектор $\vec{d} = \vec{a} - \vec{b}$, который в сумме с вектором $\vec{b}$ дает вектор $\vec{a}$ ($\vec{d} + \vec{b} = \vec{a}$).

- Геометрическое построение: Если отложить векторы $\overrightarrow{AC} = \vec{a}$ и $\overrightarrow{AB} = \vec{b}$ из общего начала, то их разность — это вектор, направленный из конца вычитаемого в конец уменьшаемого: $\overrightarrow{BC} = \vec{a} - \vec{b}$.

### Произведение вектора на число (скаляр)

Произведением вектора $\vec{a}$ на вещественное число $\alpha$ называется новый вектор $\vec{b} = \alpha \vec{a}$, удовлетворяющий условиям:

1. $\vec{b} \parallel \vec{a}$ (коллинеарность).
2. $\vert{}\vec{b}\vert{} = \vert{}\alpha\vert{} \cdot \vert{}\vec{a}\vert{}$ (длина).
3. Направление совпадает с $\vec{a}$, если $\alpha > 0$, и противоположно $\vec{a}$, если $\alpha < 0$.

_Следствия:_ $0 \cdot \vec{a} = \vec{0}$ и $(-1) \cdot \vec{a} = -\vec{a}$.

- Свойства умножения на число:
    
    - Дистрибутивность относительно сложения векторов: $\alpha(\vec{a} + \vec{b}) = \alpha\vec{a} + \alpha\vec{b}$.
    - Дистрибутивность относительно сложения чисел: $(\alpha + \beta)\vec{a} = \alpha\vec{a} + \beta\vec{a}$.
    - Ассоциативность: $\alpha(\beta\vec{a}) = (\alpha\beta)\vec{a}$.

## Критерий коллинеарности векторов

Теорема (Необходимое и достаточное условие коллинеарности):  
Два вектора $\vec{a}$ и $\vec{b}$ ($\vec{a} \neq \vec{0}$) коллинеарны тогда и только тогда, когда существует такое число $\alpha$, что:  
$$\vec{b} = \alpha \vec{a}$$

Идея доказательства достаточности через орты (единичные векторы):  
Вводятся вспомогательные единичные векторы $\vec{e}_1 = \frac{\vec{a}}{\vert{}\vec{a}\vert{}}$ и $\vec{e}_2 = \frac{\vec{b}}{\vert{}\vec{b}\vert{}}$. Поскольку исходные векторы коллинеарны, их орты либо равны, либо противоположны: $\vec{e}_1 = \pm \vec{e}_2$. Подставляя выражения выраженных векторов, получаем связь $\vec{b} = \pm \frac{\vert{}\vec{b}\vert{}}{\vert{}\vec{a}\vert{}} \vec{a}$, где коэффициент и выступает искомым числом $\alpha$.

## Примеры решения задач

### Упражнение 1 (Медианы треугольника)

В треугольнике $ABC$ проведены медианы $AK$ и $BM$. Обозначим $\overrightarrow{AK} = \vec{p}$ и $\overrightarrow{BM} = \vec{q}$. Выразить векторы сторон $\overrightarrow{AB}$ и $\overrightarrow{BC}$ через $\vec{p}$ и $\vec{q}$.

- Решение для $\overrightarrow{AB}$:  
    Точка пересечения медиан $O$ делит их в отношении $2:1$, считая от вершины. Следовательно:  
    $$\overrightarrow{AO} = \frac{2}{3}\vec{p}, \quad \overrightarrow{OB} = -\frac{2}{3}\vec{q}$$  
    По правилу треугольника из $\triangle AOB$:  
    $$\overrightarrow{AB} = \overrightarrow{AO} + \overrightarrow{OB} = \frac{2}{3}\vec{p} - \frac{2}{3}\vec{q}$$  
- Решение для $\overrightarrow{BC}$:  
    Рассмотрим точку $K$ — середину стороны $BC$. Тогда $\overrightarrow{BC} = 2\overrightarrow{BK}$.  
    Из $\triangle OBK$ найдем $\overrightarrow{BK} = \overrightarrow{BO} + \overrightarrow{OK}$.  
    Поскольку $\overrightarrow{BO} = \frac{2}{3}\vec{q}$ (направление совпадает с $\vec{q}$), а $\overrightarrow{OK} = \frac{1}{3}\vec{p}$:  
    $$\overrightarrow{BK} = \frac{2}{3}\vec{q} + \frac{1}{3}\vec{p}$$  
    $$\overrightarrow{BC} = 2\left(\frac{2}{3}\vec{q} + \frac{1}{3}\vec{p}\right) = \frac{4}{3}\vec{q} + \frac{2}{3}\vec{p}$$  

### Упражнение 2 (Параллелограмм)

Дан параллелограмм $ABCD$, где $\overrightarrow{AB} = \vec{a}$, $\overrightarrow{AD} = \vec{b}$. Точка $M$ — середина стороны $AD$. Выразить вектор $\overrightarrow{MB}$.

- Решение:  
    По правилу разности векторов или через цепочку: $\overrightarrow{MB} = \overrightarrow{MA} + \overrightarrow{AB}$.  
    Так как $M$ — середина $AD$, то $\overrightarrow{MA} = -\frac{1}{2}\overrightarrow{AD} = -\frac{1}{2}\vec{b}$.  
    $$\overrightarrow{MB} = \vec{a} - \frac{1}{2}\vec{b}$$
