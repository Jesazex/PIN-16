Тема: Свойства пределов последовательностей

## Единственность предела

Предел последовательности, если он существует, является единственным.

Доказательство (от противного):  
Предположим, что последовательность $\{x_n\}$ имеет два различных предела, $A$ и $B$, причем $A < B$. Выберем расстояние:  
$$\varepsilon = \frac{B - A}{2} > 0$$

По определению предела:

1. Существует номер $N_1$, такой что для всех $n > N_1$ выполняется неравенство $\vert{}x_n - A\vert{} < \varepsilon$, что эквивалентно:  
    $$A - \varepsilon < x_n < A + \varepsilon$$
2. Существует номер $N_2$, такой что для всех $n > N_2$ выполняется неравенство $\vert{}x_n - B\vert{} < \varepsilon$, что эквивалентно:  
    $$B - \varepsilon < x_n < B + \varepsilon$$

Возьмем $N = \max(N_1, N_2)$. Тогда для всех $n > N$ оба неравенства выполняются одновременно:  
$$x_n < A + \varepsilon \quad \text{и} \quad x_n > B - \varepsilon$$

Подставим значение $\varepsilon$:

- $A + \varepsilon = A + \frac{B - A}{2} = \frac{A + B}{2}$
- $B - \varepsilon = B - \frac{B - A}{2} = \frac{A + B}{2}$

Таким образом, для $n > N$ мы получаем $x_n < \frac{A + B}{2}$ and одновременно $x_n > \frac{A + B}{2}$. Это является противоречием. Следовательно, наше первоначальное предположение о существовании двух различных пределов неверно.

## Ограниченность сходящейся последовательности

Любая последовательность, имеющая предел (сходящаяся последовательность), является ограниченной.

Теорема: Если $\lim_{n \to \infty} x_n = A$, то существует такое число $C > 0$, что для всех $n \in \mathbb{N}$ выполняется:  
$$\vert{}x_n\vert{} \le C$$

Доказательство:  
Пусть $\lim_{n \to \infty} x_n = A$. Возьмем $\varepsilon = 1$. По определению предела, для этого $\varepsilon$ найдется такой номер $N_0$, что для всех $n >$ $N_0$ выполняется $\vert{}x_n - A\vert{} < 1$.

Используя неравенство треугольника ($\vert{}x_n\vert{} = \vert{}x_n - A + A\vert{} \le \vert{}x_n - A\vert{} + \vert{}A\vert{}$), получаем, что для всех $n > N_0$:  
$$\vert{}x_n\vert{} < 1 + \vert{}A\vert{}$$

Это неравенство выполняется для всех членов последовательности, начиная с номера $N_0 + 1$. Чтобы ограничить всю последовательность, необходимо учесть и первые $N_0$ членов. Выберем в качестве константы $C$ максимальное значение:  
$$C = \max\{\vert{}x_1\vert{}, \; \vert{}x_2\vert{}, \; \ldots, \; \vert{}x_{N_0}\vert{}, \; 1 + \vert{}A\vert{}\}$$

Таким образом, для любого натурального $n$ будет выполняться $\vert{}x_n\vert{} \le C$, что доказывает ограниченность последовательности.

## Предельный переход в неравенствах

Если даны две сходящиеся последовательности $\{x_n\}$ и $\{y_n\}$, и начиная с некоторого номера $N_0$ выполняется неравенство $x_n \le y_n$, то их пределы удовлетворяют аналогичному неравенству.

Теорема: Если $\lim_{n \to \infty} x_n = A$ и $\lim_{n \to \infty} y_n = B$, и при этом $x_n \le y_n$ для всех $n > N_0$, то:  
$$A \le B$$

Доказательство (от противного):  
Предположим, что $A > B$. Выберем $\varepsilon = \frac{A - B}{2} > 0$. Из определения предела:

1. Для $n > N_1$ имеем: $x_n > A - \varepsilon = \frac{A + B}{2}$.
2. Для $n > N_2$ имеем: $y_n < B + \varepsilon = \frac{A + B}{2}$.

Пусть $N = \max(N_0, N_1, N_2)$. Тогда для всех $n > N$ одновременно выполняются три неравенства:

- $x_n \le y_n$ (по условию)
- $y_n < \frac{A + B}{2}$
- $x_n > \frac{A + B}{2}$

Из последних двух соотношений следует, что $y_n < x_n$, что напрямую противоречит условию $x_n \le y_n$. Следовательно, предположение $A > B$ неверно, и должно быть $A \le B$.

- Замечания: Строгое неравенство между последовательностями ($x_n < y_n$) при переходе к пределу может превратиться в нестрогое ($A \le B$).
- _Пример:_ $x_n = -\frac{1}{n}$ и $y_n = \frac{1}{n}$. Для всех $n$ выполняется $x_n < y_n$, но их пределы равны между собой: $\lim_{n \to \infty} x_n = 0$ и $\lim_{n \to \infty} y_n = 0$.

## Теорема о двух милиционерах

_Если последовательность $\{y_n\}$ заключена между двумя другими последовательностями $\{x_n\}$ и $\{z_n\}$, сходящимися к одному и тому же пределу, то она также сходится к этому пределу._

Теорема: Если для всех $n > N_0$ выполняется $x_n \le y_n \le z_n$, и при этом $\lim_{n \to \infty} x_n = \lim_{n \to \infty} z_n = A$, то:  
$$\lim_{n \to \infty} y_n = A$$

Доказательство:  
Для любого произвольного $\varepsilon > 0$ существуют номера $N_1$ и $N_2$ такие, что:

- Для всех $n > N_1$: $A - \varepsilon < x_n < A + \varepsilon$
- Для всех $n > N_2$: $A - \varepsilon < z_n < A + \varepsilon$

Пусть $N = \max(N_0, N_1, N_2)$. Тогда для всех номеров $n > N$ справедливо:  
$$A - \varepsilon < x_n \le y_n \le z_n < A + \varepsilon$$

Отсюда следует, что $A - \varepsilon < y_n < A + \varepsilon$, что по определению предела означает $\lim_{n \to \infty} y_n = A$.

## Теорема о сохранении знака

_Если предел последовательности отличен от нуля, то начиная с некоторого номера все члены последовательности имеют тот же знак, что и их предел._

Теорема: Пусть $\lim_{n \to \infty} x_n = A$ и $A \ne 0$. Тогда найдется номер $N_0$ такой, что для всех $n > N_0$ знак $x_n$ совпадает со знаком $A$.

Доказательство:  
Выберем $\varepsilon = \frac{\vert{}A\vert{}}{2} > 0$. По определению предела, для этого $\varepsilon$ существует $N_0$, такое что для всех $n > N_0$ выполняется $\vert{}x_n - A\vert{} < \frac{\vert{}A\vert{}}{2}$, или:  
$$A - \frac{\vert{}A\vert{}}{2} < x_n < A + \frac{\vert{}A\vert{}}{2}$$

- Если $A > 0$: получаем $\frac{A}{2} < x_n < \frac{3A}{2}$. Отсюда напрямую следует, что $x_n > 0$.
- Если $A < 0$: получаем $\frac{3A}{2} < x_n < \frac{A}{2}$. Отсюда напрямую следует, что $x_n < 0$.

## Бесконечно малые и бесконечно большие последовательности

- Определение: Последовательность $\{\alpha_n\}$ называется бесконечно малой, если ее предел равен нулю: $\lim_{n \to \infty} \alpha_n = 0$.
- Связь с пределом: Последовательность $\{x_n\}$ имеет предел $A$ тогда и только тогда, когда последовательность $\{\alpha_n\} = \{x_n - A\}$ является бесконечно малой.

## Свойства бесконечно малых последовательностей

1. Сумма или разность двух бесконечно малых последовательностей есть бесконечно малая последовательность.
2. Произведение ограниченной последовательности на бесконечно малую есть бесконечно малая последовательность.
3. Произведение конечного числа бесконечно малых последовательностей есть бесконечно малая последовательность.
4. Произведение константы на бесконечно малую последовательность есть бесконечно малая.

- Определение: Последовательность $\{x_n\}$ называется бесконечно большой, если для любого числа $M > 0$ (сколь угодно большого) найдется номер $N_0$, такой что для всех $n > N_0$ выполняется $\vert{}x_n\vert{} > M$. Обозначается:  
    $$\lim_{n \to \infty} x_n = \infty$$
    
    - Если $x_n > M$, пишут $\lim_{n \to \infty} x_n = +\infty$.
    - Если $x_n < -M$, пишут $\lim_{n \to \infty} x_n = -\infty$.
    
- Взаимосвязь: Если $\{x_n\}$ — бесконечно большая последовательность без нулевых членов, то $\{\frac{1}{x_n}\}$ — бесконечно малая. И наоборот, если $\{\alpha_n\}$ — бесконечно малая и $\alpha_n \ne 0$, то $\{\frac{1}{\alpha_n}\}$ — бесконечно большая.

## Арифметические операции с пределами

Если существуют $\lim_{n \to \infty} x_n = A$ и $\lim_{n \to \infty} y_n = B$, то:

1. $\lim_{n \to \infty} (x_n \pm y_n) = A \pm B$
2. $\lim_{n \to \infty} (C \cdot x_n) = C \cdot A$, где $C = \text{const}$.
3. $\lim_{n \to \infty} (x_n \cdot y_n) = A \cdot B$
4. $\lim_{n \to \infty} \frac{1}{y_n} = \frac{1}{B}$ (при $B \ne 0$)
5. $\lim_{n \to \infty} \frac{x_n}{y_n} = \frac{A}{B}$ (при $B \ne 0$)

## Пример доказательства для произведения (п. 3)

Доказательства данных свойств удобно проводить через разложение на бесконечно малые последовательности:  
$$x_n \cdot y_n - A \cdot B = (x_n - A) \cdot y_n + A \cdot (y_n - B)$$

Здесь разности $(x_n - A)$ и $(y_n - B)$ представляют собой бесконечно малые последовательности. Последовательность $\{y_n\}$ сходится, следовательно, она ограничена. Величина $A$ — константа.

В результате все выражение является суммой двух бесконечно малых последовательностей, что также дает бесконечно малую последовательность. Это строго доказывает, что:  
$$\lim_{n \to \infty} (x_n \cdot y_n - A \cdot B) = 0 \implies \lim_{n \to \infty} (x_n \cdot y_n) = A \cdot B$$

## Теорема Вейерштрасса о пределе монотонной последовательности

Любая монотонная и ограниченная последовательность имеет конечный предел.

- Если последовательность не убывает и ограничена сверху, ее предел равен ее точной верхней грани: $\lim_{n \to \infty} x_n = \sup\{x_n\}$.
- Если последовательность не возрастает и ограничена снизу, ее предел равен ее точной нижней грани: $\lim_{n \to \infty} x_n = \inf\{x_n\}$.

Доказательство (для не убывающей последовательности):  
Пусть $\{x_n\}$ — не убывающая и ограниченная сверху последовательность. Множество ее значений ограничено сверху, а значит, по теореме о существовании точной грани, имеет супремум. Обозначим его $M = \sup\{x_n\}$. Докажем, что $\lim_{n \to \infty} x_n = M$.

1. По определению супремума, для любого натурального $n$ выполняется неравенство $x_n \le M$. Поскольку $M < M + \varepsilon$ при любом $\varepsilon > 0$, то:  
    $$x_n < M + \varepsilon$$
2. По второму свойству супремума, для любого $\varepsilon > 0$ обязательно найдется хотя бы один элемент последовательности $x_{N_0}$ такой, что:  
    $$x_{N_0} > M - \varepsilon$$

Так как последовательность является не убывающей, то для всех последующих номеров $n > N_0$ справедливо неравенство $x_n \ge x_{N_0}$.

Объединяя оба шага, получаем, что для всех номеров $n > N_0$ выполняется двойное неравенство:  
$$M - \varepsilon < x_n < M + \varepsilon \iff \vert{}x_n - M\vert{} < \varepsilon$$

Это в точности соответствует определению предела, следовательно, $\lim_{n \to \infty} x_n = M$.
