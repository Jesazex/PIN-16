## 1. Свойства супремума и инфимума сумм множеств

Рассматриваются два непустых множества действительных чисел $X$ и $Y$. Пусть:  
$$\sup X = m_1, \quad \sup Y = m_2$$

Теорема: $\sup(X+Y) = m_1 + m_2$, где $X+Y = \{x+y \mid x \in X, \, y \in Y\}$.

## Доказательство

#### 1) Верхняя грань

Для всех $x ∈ X$ выполняется $x ≤ m_1$, а для всех $y ∈ Y$ выполняется $y ≤ m_2$. Тогда для любого элемента $z ∈ X+Y$ (где $z=x+y$) справедливо:  
$$z = x+y \le m_1 + m_2$$  
Следовательно, число $m_1 + m_2$ является верхней гранью множества $X+Y$.

#### 2) Наименьшая из верхних граней

Пусть $ε > 0$. По определению точной верхней грани:

- существует $x_\varepsilon \in X$ такое, что $x_\varepsilon > m_1 - \frac{\varepsilon}{2}$;
- существует $y_\varepsilon \in Y$ такое, что $y_\varepsilon > m_2 - \frac{\varepsilon}{2}$.

Сложив эти неравенства, получим:  
$$z_\varepsilon = x_\varepsilon + y_\varepsilon > \left(m_1 - \frac{\varepsilon}{2}\right) + \left(m_2 - \frac{\varepsilon}{2}\right) = m_1 + m_2 - \varepsilon$$

Таким образом, для любого $ε > 0$ в множестве $X+Y$ найдётся элемент $z_\varepsilon$, превосходящий $(m_1 + m_2 - ε)$. Это доказывает, что:  
$$\sup(X+Y) = m_1 + m_2$$

---

## Аналогичное свойство для инфимума

$$\inf(X+Y) = \inf X + \inf Y$$

## Доказательство через связь супремума и инфимума

Используя тождества $\inf X = -\sup(-X)$ и $\sup X = -\inf(-X)$, запишем:  
$$\inf(X+Y) = -\sup(-(X+Y)) = -\sup((-X)+(-Y)) = -(\sup(-X)+\sup(-Y)) = \inf X + \inf Y$$

## 2. Лемма о сечении (лемма Дедекинда) и существование точных граней

## Формулировка леммы

Пусть заданы два непустых подмножества $A \subset \mathbb{R}$ и $B \subset \mathbb{R}$, удовлетворяющие условиям:

1. $A \cup B = \mathbb{R}$
2. Для любых a ∈ A и b ∈ B выполнено неравенство a < b

Тогда либо в множестве $A$ существует наибольший элемент, либо в множестве $B$ существует наименьший элемент.

## Теорема о существовании супремума

Пусть непустое множество $X \subset \mathbb{R}$ ограничено сверху. Рассмотрим множество всех его верхних граней $B$ и его дополнение $A = \mathbb{R} \setminus B$.

- Множество $A$ непусто (если $x_0 ∈ X$, то элемент $(x_0-1) ∈ A$).
- Множество $B$ непусто (по условию ограниченности $X$ сверху).
- По построению $A \cup B = \mathbb{R}$.
- Для любых $a ∈ A$ и $b ∈ B$ выполнено $a < b$. _Если бы существовали такие элементы, что $a ≥ b$, то по свойству верхней грани число a также являлось бы верхней гранью множества $X$, что противоречит условию $a ∈ A$._

По лемме Дедекинда, в множестве верхних граней B обязательно существует наименьший элемент — он и является точной верхней гранью $\sup X$.

## 3. Пределы последовательности

- Последовательность: Отображение вида $x: \mathbb{N} \to \mathbb{R}$, которое обозначается как $\{x_n\}_{n=1}^\infty$.
- Окрестность точки $x_0$: Любой интервал $(a, b)$, содержащий эту точку. Симметричная ε-окрестность задается интервалом $(x₀-ε, x₀+ε)$.
- Предельная точка: Число a называется предельной точкой последовательности, если в любой его окрестности содержится бесконечно много членов этой последовательности.  
    $$\forall \varepsilon > 0, \quad \forall N \in \mathbb{N}, \quad \exists n \ge N: \; \vert{}x_n - a\vert{} < \varepsilon$$
#### Словесная формулировка:  
Для любого (какого бы то ни было) положительного числа эпсилон ($\varepsilon > 0$) и для любого (сколько угодно большого) натурального числа $N$, найдется такой натуральный индекс (номер члена последовательности) $n$, который больше или равен $N$, что расстояние от этого члена последовательности $x_n$ до точки $a$ будет строго меньше, чем эпсилон (то есть элемент $x_n$ попадет в заданную эпсилон-окрестность точки $a$).
## Предел последовательности

$$\lim_{n \to \infty} x_n = a \iff \forall \varepsilon > 0 \quad \exists N \in \mathbb{N} \quad \forall n \ge N: \; \vert{}x_n - a\vert{} < \varepsilon$$
##### Словесная формулировка:
Число $a$ называется пределом последовательности $x_n$ при $n$, стремящемся к бесконечности, тогда и только тогда, когда для любого заранее заданного положительного числа эпсилон ($\varepsilon > 0$) существует зависящий от него натуральный номер $N$, такой, что для абсолютно всех натуральных номеров $n$, которые больше или равны этому $N$, выполняется неравенство: модуль разности $x_n$ и $a$ строго меньше эпсилон (все члены последовательности, начиная с номера $N$, лежат внутри эпсилон-окрестности точки $a$).
## Взаимосвязь понятий:

- Если $\lim_{n \to \infty} x_n = a$, то число a гарантированно является предельной точкой.
- Обратное утверждение неверно: наличие предельной точки не гарантирует существование предела. Если у последовательности более одной предельной точки, предел не существует.

## Пример доказательства по определению

Доказать, что $\lim_{n \to \infty} \frac{1}{n} = 0$.

Для произвольного $ε > 0$ выберем индекс $N = \lceil \varepsilon^{-1} \rceil$. Тогда для всех номеров $n ≥ N$ выполняется:  
$$\left\vert{}\frac{1}{n} - 0\right\vert{} = \frac{1}{n} \le \frac{1}{N} \le \varepsilon$$

## 4. Пример оценки предела рациональной последовательности

Рассматривается доказательство предела следующего вида:  
$$\lim_{n \to \infty} \frac{P_3(n)}{Q_4(n)} = 0$$  
где $P_3(n)$ — многочлен 3-й степени, а $Q_4(n)$ — многочлен 4-й степени.

## Стратегия доказательства (метод оценок)

1. Оценка числителя сверху: Начиная с некоторого номера $N_1$, модуль многочлена числителя можно ограничить старшей степенью:  
    $$\vert{}P_3(n)\vert{} \le C \cdot n^3$$
2. Оценка знаменателя снизу: Начиная с некоторого номера $N_2$, модуль многочлена знаменателя можно ограничить снизу:  
    $$\vert{}Q_4(n)\vert{} \ge \alpha \cdot n^4 \quad (\alpha > 0)$$
3. Совмещение полученных оценок: Для всех индексов $n \ge \max(N_1, N_2)$ справедливо неравенство:  
    $$\left\vert{}\frac{P_3(n)}{Q_4(n)}\right\vert{} \le \frac{C \cdot n^3}{\alpha \cdot n^4} = \frac{C}{\alpha} \cdot \frac{1}{n}$$

Если выбрать граничный номер $N_3 \ge \frac{C}{\alpha \varepsilon}$, то для всех номеров $n \ge \max(N_1, N_2, N_3)$ требование определения предела $\vert{}x_n - 0\vert{} < \varepsilon$ будет полностью выполнено.
