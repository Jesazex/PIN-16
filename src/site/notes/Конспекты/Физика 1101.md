## Краткое содержание

Лекция представляет собой введение в курс физики, состоящий из трех модулей: механика, термодинамика, электричество и магнетизм. Лектор, Александр Борисович, объясняет организационные аспекты курса, включая накопительную балльную систему, использование платформы ОРИОКС, структуру контрольных мероприятий, домашних заданий и экзамена. Также предоставляется список рекомендованной учебной литературы и задачников.

Вторая часть лекции посвящена введению в классическую механику: даются определения основных понятий (пространство, время, материальная точка, траектория), описываются разделы механики, история ее развития и подробно рассматриваются основы кинематики. Изучается прямолинейное и криволинейное движение, включая понятия скорости, ускорения (тангенциального и нормального). В завершение приводится подробный разбор задач на нахождение уравнения траектории и на определение зависимости скорости от времени и пройденного пути при движении по окружности с заданным соотношением ускорений.

## 2. Основы классической механики

- Основные понятия:
    
    - Механика: раздел физики, изучающий взаимное движение тел в пространстве и во времени.
    - Материальная точка (частица): тело, размерами которого в условиях данной задачи можно пренебречь.
    - Траектория: геометрическое место точек, в которых частица находилась в процессе движения.
    
- История развития механики:
    
    - Классическая механика (Ньютон, 1687 г.): применима для скоростей $v \ll c$ и макроскопических тел.
    - Релятивистская механика (Эйнштейн, 1905 г.): для скоростей, близких к скорости света.
    - Квантовая механика (Шрёдингер, Гейзенберг, 1925 г.): для микрочастиц (размеры < 100 нм).
    - Релятивистская квантовая механика (Дирак, 1928 г.): для микрочастиц с релятивистскими скоростями.

## 3. Кинематика движения

## Прямолинейное движение

- Средняя скорость:  
    $$\langle v_x \rangle = \frac{\Delta x}{\Delta t}$$
- Мгновенная скорость:  
    $$v_x = \frac{dx}{dt}$$
- Ускорение:  
    $$a = \frac{dv}{dt}$$

## Векторный способ описания движения

- Радиус-вектор: $\vec{r}$.
- Перемещение:  
    $$\Delta \vec{r} = \vec{r}_2 - \vec{r}_1$$
- Вектор мгновенной скорости:  
    $$\vec{v} = \frac{d\vec{r}}{dt}$$

## Тангенциальное и нормальное ускорение

- Вектор полного ускорения:  
    $$\vec{a} = \vec{a}_{\tau} + \vec{a}_n$$
- Тангенциальное ускорение (характеризует изменение модуля скорости):  
    $$\vec{a}_{\tau} = \frac{dv}{dt} \vec{\tau}$$
- Нормальное (центростремительное) ускорение (характеризует изменение направления скорости):  
    $$\vec{a}_n = \frac{v^2}{R} \vec{n}$$
- Модуль полного ускорения:  
    $$\vert{}\vec{a}\vert{} = \sqrt{a_{\tau}^2 + a_n^2}$$

## Координатное представление

- Разложение радиус-вектора:  
    $$\vec{r} = x\vec{i} + y\vec{j} + z\vec{k}$$
- Разложение вектора скорости:  
    $$\vec{v} = v_x\vec{i} + v_y\vec{j} + v_z\vec{k}, \quad \text{где} \quad v_x = \frac{dx}{dt}$$
- Тангенциальное ускорение через скалярное произведение:  
    $$a_{\tau} = \frac{\vec{a} \cdot \vec{v}}{\vert{}\vec{v}\vert{}}$$

## 4. Примеры решения задач

## Задача 1: Нахождение уравнения траектории

- Условие: $x(t) = αt$, $y(t) = βt^2$.
- Решение:
    
    1. Уравнение траектории выражается исключением времени t:  
        $$t = \frac{x}{\alpha} \implies y = \beta \left( \frac{x}{\alpha} \right)^2 = \frac{\beta}{\alpha^2} x^2 \quad \text{(парабола)}$$
    2. Проекции скорости: $v_x = \alpha$, $v_y = 2\beta t$. Модуль скорости:  
        $$\vert{}\vec{v}\vert{} = \sqrt{\alpha^2 + (2\beta t)^2}$$
    3. Проекции ускорения: $a_x = 0$, $a_y = 2\beta$. Модуль ускорения:  
        $$\vert{}\vec{a}\vert{} = 2\beta$$
    4. Угол φ между $\vec{v}$ и $\vec{a}$:  
        $$\tan \varphi = \frac{v_x}{v_y} = \frac{\alpha}{2\beta t}$$
    

## Задача 2: Движение по окружности при $\vert{}a_{\tau}\vert{} = \vert{}a_n\vert{}$

- Условие: Точка движется по окружности радиуса $R$ с замедлением.
- Решение для $v(t)$:  
    Из условия замедления $-\frac{dv}{dt} = \frac{v^2}{R}$ методом разделения переменных:  
    $$\int \frac{dv}{v^2} = -\int \frac{dt}{R} \implies \frac{1}{v} = \frac{t}{R} + \frac{1}{v_0} \implies v(t) = \frac{v_0 R}{R + v_0 t}$$
- Решение для $v(s)$:  
    Используя тождество $\frac{dv}{dt} = \frac{dv}{ds} \cdot \frac{ds}{dt} = v \frac{dv}{ds}$, перепишем уравнение как $-v \frac{dv}{ds} = \frac{v^2}{R}$.  
    После разделения переменных:  
    $$\int \frac{dv}{v} = -\int \frac{ds}{R} \implies \ln v = -\frac{s}{R} + C \implies v(s) = v_0 e^{-\frac{s}{R}}$$
